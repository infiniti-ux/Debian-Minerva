# Aluminium OS — desktop preview reference

18 screenshots collected from the two public leak waves, curated into a local
gallery for design reference while building Debian Minerva.

- **`index.html`** — offline gallery (filter by leak wave, lightbox, source links)
- **`contact-sheet.jpg`** — all 18 in one image
- **`manifest.json`** — per-image title, notes, dimensions, source URL, credit
- **`images/`** — the screenshots themselves
- **`render.py`** — regenerates the gallery + contact sheet (`python3 render.py`,
  needs Pillow)

## Groups

| Group | Source | Build |
|---|---|---|
| `01`–`04` | Jan 2026 Google Issue Tracker bug report | ALOS / Android 16, HP Elite Dragonfly |
| `05`–`18` | May 2026 Mystic Leaks video + gallery | Android 17, MacBook Pro via UTM |
